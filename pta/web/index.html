PTA 助手

把流程交给工具，
把时间留给思考。

本地运行的拼题 A 学习助手：浏览题目、在线编码、一键提交并查看判题结果。登录态只保存在你自己的机器上。

  • 读题、编辑、提交，一个界面搞定
  • 从 answers/ 目录批量提交未通过题
  • 提交后自动轮询判题，结果即时可见

登录

选择一种方式接入你的 PTA 账号。

点击后会弹出浏览器并自动填好账号密码，你只需拖动滑块并点登录，成功后自动抓取 cookie。需先安装 Playwright（见 README）。

登录 PTA 后，F12 → 网络 → 任意 api/ 请求 → 复制请求头里整条 Cookie 值，粘贴到下面。

登录态保存在本机，只随请求发送到你配置的 PTA/Pintia 服务。
非官方工具，与 PTA/Pintia 无隶属关系。
